# 产品需求文档

## 用户流程

1. 首页进入制作。
2. 选择音乐。
3. 设置礼物内容。
4. 预览礼物。
5. 生成分享链接。
6. 收礼人打开礼物页并互动。

## 音乐选择

支持四种方式：

1. 粘贴 QQ 音乐 / 酷狗链接。
2. 输入歌手名或场景关键词搜索推荐。
3. 上传本地音频。
4. 使用内置默认 BGM。

音频上传限制：

- 格式：mp3 / wav / m4a
- 大小：15MB 以内

## 礼物内容

- 称呼：默认 `XX`，用户可编辑，最多 15 字。
- 标题：默认 `给XX的礼物`。
- 祝福语：最多 50 字。
- 祝福语字号：用户可在 5px - 20px 间调节。
- 背景图：上传图片或选择默认模板。
- 主题：樱花粉、晨光绿、奶油黄、淡雅蓝。
- 祝福流速：默认舒缓，可手动调慢或调快。
- 祝福语占比：用户可选择 15%、30%、50%、75%，占比从页面顶部开始计算。
- 祝福语行距：用户可在祝福语占比区域内按 0.5x - 1.2x 调节多行祝福的行距。

## 礼物页

- 背景图模糊 + 浅色蒙版。
- 中央 2D 音乐盒、草地、飘动音符与多朵花。
- `给XX的礼物` 标题放在 BloomBeat 音乐盒便签内，不固定在页面顶部。
- 祝福语循环流动。
- 祝福语在交互页由字符组成波浪线形状并横向流动，不使用波浪下划线。
- 左上角实时数据面板。
- 首次进入显示手势引导蒙层。
- 支持摄像头手势与触摸兜底。
- 进入礼物页时应尝试默认播放音乐，按钮用于暂停；若浏览器拦截自动播放，则按钮提示用户点击播放。
- 花朵初始颜色与主题色一致；换色时整片花园统一随机变为新的颜色。
- 单击用于花朵开合，双击用于统一换色；双击不应触发第一次单击的开合动作。
- 花朵升高 / 降低需要有明显幅度，叶子随高度同步移动。
- 无操作时花朵应像风铃绳子一样缓慢、轻柔地自然摆动。
- 左右挥动时只让花朵随风摇动，草地和音乐盒便签保持稳定。
- 左右挥动时页面需要出现轻微风吹 / 水波纹式波动。
- 音乐控制使用喇叭图标按钮；点击后进入静音，BGM 关闭。
- 喇叭图标位于交互页左下角。
