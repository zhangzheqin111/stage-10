# 项目总览

## 项目名称

BloomBeat（花律）

## 一句话定位

一个治愈系 2D 互动音乐礼物 H5。用户选择音乐、图片和祝福语，生成一份可以分享的互动礼物。

## 目标用户

- 想制作生日、表白、感谢、鼓励、陪伴类音乐礼物的用户。
- 收到礼物后希望以轻松方式体验音乐和互动的用户。

## 最终交付

- 可真实上线的 H5 网页。
- 可匿名生成分享链接。
- 支持 QQ 音乐 / 酷狗链接解析逻辑与 mock 兜底。
- 支持用户上传音频，限制 10MB。
- 支持 4 张默认模板图。
- 支持摄像头手势互动与触摸兜底。
- 项目内包含完整 docs 文档与 dev-logs 开发日志。
