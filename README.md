# BloomBeat（花律）

BloomBeat（花律）是一个治愈系 2D 互动音乐礼物 H5。用户选择 QQ 音乐 / 酷狗歌曲、上传音频或使用默认 BGM，搭配图片与祝福语生成可分享链接。收礼人打开后，可以通过摄像头手势或触摸操作让音乐盒中的花朵生长、摇摆、开放和变色。

## 核心原则

- 移动端 H5 优先。
- 礼物页必须更像礼物体验，而不是编辑器。
- 黑客松版本不做登录，匿名生成分享链接。
- 音乐 API、摄像头识别、上传能力都必须有兜底。
- 按阶段开发，每阶段完成后必须验收并更新开发日志。
