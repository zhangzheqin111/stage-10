# 互动与手势规范

## 手势引导蒙层

- 首次进入礼物页自动显示。
- 展示 4 种手势图标和说明。
- 3 秒后自动消失。
- 可点击“我知道了”关闭。
- 点击左上角 `?` 可重新查看。

## 手势映射

| 手势 | 效果 |
|---|---|
| 上下摆动 | 花朵变高 / 变矮 |
| 左右挥动 | 音量变化，并产生风 |
| 张开 / 握拳 | 花朵开放 / 闭合 |
| 拍手 / 快速合拢 | 花朵切换颜色 |

## 触摸兜底

| 触摸操作 | 效果 |
|---|---|
| 上下滑动 | 花朵变高 / 变矮 |
| 左右滑动 | 调整音量和风力 |
| 点击花朵 | 花朵开放 / 闭合 |
| 双击屏幕 | 花朵切换颜色 |

## 音量映射

- 花朵越高，音量越大；花朵越矮，音量越小。
- 左右滑动时，越靠左音量越小，越靠右音量越大。
- 手势引导中需要说明上下滑动和左右滑动对音量的影响。
