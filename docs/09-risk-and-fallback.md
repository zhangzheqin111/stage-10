# 风险与兜底

## 音乐 API 风险

QQ 音乐 / 酷狗可能无法直接获取播放地址。

兜底：

1. mock 解析结果。
2. 搜索推荐。
3. 用户上传音频。
4. 默认 BGM。

## 摄像头风险

用户可能拒绝授权，或浏览器不支持。

兜底：

- 自动进入触摸模式。

## 上传风险

音频过大或上传失败。

兜底：

- 限制 10MB。
- 给出重试提示。
- 允许选择默认 BGM。

## 分享风险

本地文件无法被收礼人访问。

解决：

- 图片和音频必须上传到云存储。
- 分享链接只保存资源 URL 和 Gift 配置。
- 未配置 Supabase 时只能使用 IndexedDB 本地兜底，适合同一设备验收，不代表跨设备上线能力。
