- **修复**：
  1. 杀掉旧 `next dev` (PID 25436) 和旧 cloudflared 进程。
  2. `npm run build` 生产构建（5.5s 编译 + 8.1s TypeScript，11 路由零错误）。
  3. `nohup next start --hostname 0.0.0.0 --port 3000` 启动生产服务器（PID 1264）。
  4. `nohup cloudflared.exe tunnel --url http://localhost:3000` 新建隧道。
  5. 验证结果：所有路由 + `/_next/static/chunks/*.js` 全 200。
- **诊断辅助**：在选歌页和内容页顶部添加 `DebugBanner`（实时显示 Song/Selected/Audio/Image/Flow 状态），手机端可直接看到 localStorage 写入是否生效。
